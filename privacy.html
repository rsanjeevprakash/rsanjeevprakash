SMM Uploader: Privacy Policy

Last updated: 24 November 2026

SMM Uploader is a personal tool used only by its owner to manage the owner's own YouTube channel and Instagram account. It is not offered to the public.

What data it accesses

  • Through Google sign-in (YouTube Data API and YouTube Analytics API): permission to upload videos to the owner's channel, read and update the channel's basic settings, and read the channel's analytics reports.
  • Through Instagram sign-in (Instagram API): permission to publish Reels to the owner's account and read their insights.

How it is used and stored

  • Data is used only to upload the owner's videos and to show the owner their own performance statistics.
  • Sign-in tokens and analytics are stored only on the owner's own computer, in Windows Credential Manager and a local database. Nothing is sent to any server operated by this tool.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services

SMM Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions (Google) and in Instagram under Settings → Website permissions → Apps and websites. Deleting the tool's local folder deletes all stored data.
